# 知办AI

知办AI 是面向团队的 AI 协作项目，社区版以桌面客户端、服务端和 Agent 接入能力为交付方向。

## 发布状态

源码候选版本为 v0.1.0-rc.1。公开范围包括桌面客户端及共享包、本地桥接、社区后端、社区管理台、DSH 运行时与本地 Compose 部署；移动端和商业支付不在本次范围。

已在 macOS 本地环境验证社区服务启动、登录、租户、Mock 对话、文件上传下载和服务端消息链路；社区后端与管理台已分别完成隔离构建。完整公开树构建、桌面 SDK 连接、管理台完整浏览器流程与 Windows 验收尚未完成。本候选不提供已验收的签名桌面安装包，不代表正式版本已经发布。
