# ADR-0003：社区版可选服务器工作区

状态：采用。

桌面入口组合本地工作区与既有服务端 MyApp。连接地址是运行时工作区配置，与 communityEdition 独立；默认本地，每次连接重新认证。共享包定义连接/地址检测与会话隔离，桌面负责工作区组合，禁止共享包反向依赖 App。

切换先卸载页面，再清理旧会话及网络，最后设置新地址、重建路由。保留唯一业务页面，不复制登录或服务端 Provider。当前不引入通用插件系统、多服务器同时在线和自动数据迁移。见 [需求与验收](../requirements/server-workspace.md)。

2026-11-12 决策补充：后台页面和服务端直接复用内网已有版本；本轮扩展的管理端、业务接口和 000014–000022 SQL 撤销。原 13 份社区迁移及标准运行器保持不变，现有数据库数据和迁移账本保留；导出缺漏记录为限制，不继续补功能。客户端保留连接隔离与用户明确要求的未读、布局和员工分类修复。

## 2026-11-17：本机完整后台授权后的接入边界

后续用户已明确要求本机后端与完整后台可用，按追加社区迁移复用原实现；11 月 12 日“暂停扩展”是历史范围。此次采用原 OIDC 联邦认证，SSO 会话只属于配置 IdP 的租户。采用原角色权限点、按当前作用域计算后台资格，不自动给企业登录成员管理员角色。state 同时绑定浏览器 HttpOnly Cookie 与 Redis 单次记录；已有账号首次邮箱匹配要求 email_verified。新增 nullable auth_tenant_id 保存刷新和切范围不可扩张的认证边界，密码登录保持 NULL。依据及适配判断见需求中的 OWASP Authentication/OAuth2。

用户纠正：应用关联数字员工，客户端通过员工对话的既有入口打开；不新增工作台 Tab。目录和启动统一遵守租户启用开关，停用保留绑定、解绑后删除绑定；缓存旧入口同样须由后端拒绝。继续复用现有单次授权码及原生应用面板，不向 H5 传入客户端登录 token。
