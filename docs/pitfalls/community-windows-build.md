# Windows 社区版构建

- CMake 配置测试会创建占位源码；runner 增加源文件后，测试夹具也必须同步。例如 desktop_network_bridge.cpp 已在实际源码中，但旧夹具未创建它，导致配置测试假失败。不可通过删除生产构建源文件修复。
- 构建机 C 盘空间不足时用独立短路径目录，复用经摘要校验的依赖缓存；不得重置已有工作区。
- AppContainer 自检需要交互会话；SSH 进程环境与交互用户环境不同。构建使用独立手动计划任务，安装验收另外使用普通权限，不能把构建自检等同于安装通过。
- 社区导出必须包含打包脚本的传递依赖。Windows bundler 调用 scripts/build-codex-windows.py，遗漏会在构建时失败；同时导出缓存信任检查测试，保留源码、补丁、工具链和二进制摘要校验。
